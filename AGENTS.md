# Repository conventions

- Keep each skill self-contained under skills/<skill-name>/, including its instructions, scripts, references, and assets.
- Match each skill folder name to its frontmatter name. Update metadata and references when renaming a skill.
- Keep each skill's root README catalog description identical to its SKILL.md frontmatter description.
- Keep skill-specific rules in that skill's SKILL.md or supporting references.
- Keep local experiments in the ignored examples/ directory.
- Run checks relevant to the skill and files changed.
- Use Conventional Commits: `<type>(optional-scope): <description>` (e.g. `feat(better-walkthrough): add zoom controls` or `docs: update catalog`).
