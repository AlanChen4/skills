# Skills

A collection of agents skills to make more delightful software.

## Available skills

- [**better-clear-language**](skills/better-clear-language/SKILL.md): Write and revise clear English for policies, instructions, knowledge bases, user messages, reports, and spoken delivery. Use when a user asks for clear language, ASD-STE100 style, plain English, concise prose, or text that follows the Lumos clear-language rules.
- [**better-one-by-one**](skills/better-one-by-one/SKILL.md): Work through mentioned issues/tasks one by one, with progress tracker.
- [**better-walkthrough**](skills/better-walkthrough/SKILL.md): Use [D2 diagrams](https://d2lang.com/) to walk through code logic step-by-step.

## Install

```sh
npx skills add AlanChen4/skills -g
```
