# Better one by one

Show a numbered list of the user's items, then start with `(1/N) Item title`, where N is the total. Work only on the current item. Show `(i/N) Item title` in each response. Wait for the user's reply before advancing; move on when the item is resolved or the user asks to continue or skip. Example: for three issues, start with `(1/3) Fix login`.
